# Baselines

- `copy-last-year.csv`: the status quo. Last year's answers from
  `company/knowledge/answers.jsonl`, pasted into this year's questions, which is
  what most teams do. It exists mainly to show the scorer has teeth.
- `../../out/baseline/harbor-bank-solo.csv`: a solo agent. One Claude Code
  session with the same files and no people (`eval/solo_prompt.md`).
